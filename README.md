## 🎨 Interactive Features Showcase

### 1. 🖥️ Developer CLI Terminal (Interactive Section)
Includes an in-browser mock console (`guest@sunilthatra:~$`) designed to print structured profile neofetch logs, competency charts, and trigger digital rain overlay effects.

<details>
<summary><b>🕹️ Try these commands in the live terminal:</b></summary>
<br>

* `help` - Show list of commands
* `about` - Overview of Sunil's development guidelines
* `skills` - Render ASCII progress bars showing competency levels
* `projects` - Highlights of Saarthi, Heal Ayur, and CodeConnect
* `neofetch` - Custom B.Tech student status & target specs card
* `matrix` - Toggles falling green digital rain canvas animation!
* `secret` - Unlocks easter egg ASCII art
* `clear` - Wipes console outputs
</details>

### 2. 📯 3D Mouse Parallax
Hovering over the portrait image card in the hero fold tilts it relative to the cursor position while translating layers on the Z-axis, creating a modern 3D illusion.

### 3. 🌐 Canvas Particle Grid
Draws floating connected points across the entire screen, responsive to mouse coordinates for active attraction/repulsion nodes.

## 🛠️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/thatrasunil/personal-portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd personal-portfolio
   ```
3. Start a local server:
   - **Using Python 3**:
     ```bash
     python -m http.server 8000
     ```
   - **Using Node (npx)**:
     ```bash
     npx http-server -p 8000
     ```
4. Open your browser and navigate to `http://localhost:8000`.
